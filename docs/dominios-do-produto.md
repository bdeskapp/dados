## Req.tpAgenteReg

Canal de abertura da requisição. Requisições sem código gravam `NULL`; isso inclui as aberturas que não informam o canal, como as tarefas simples da web. O rótulo descreve o caminho de abertura (decisão do produto).

| chave | rótulo | categoria |
|---|---|---|
| `A` | automática | definido pelo produto |
| `E` | e-mail | definido pelo produto |
| `M` | abertura pelas telas de atendimento ou por desdobramento | definido pelo produto |
| `P` | processo (fluxo) | definido pelo produto |
| `R` | agenda recorrente | definido pelo produto |
| `X` | abertura pela tela de pedido do portal web ou pela API | definido pelo produto |

## ReqHistorico.tpRegistro

Classificação do registro do histórico. Cada tipo é conhecido só pelo contexto em que é gravado: `A` e `R` na ação (`R` na ação `ACO`), `M` na mensagem, `D` no documento anexado ou na nova versão do documento e `P` no participante. Sem rótulo, porque não há nome oficial para cada tipo.

| chave | categoria |
|---|---|
| `A` | definido pelo produto |
| `D` | definido pelo produto |
| `M` | definido pelo produto |
| `P` | definido pelo produto |
| `R` | definido pelo produto |

|---|---|
| `0` | definido pelo produto |
| `1` | definido pelo produto |

## RotinaMapaVar.tpCopiaLocalizacao

Cópia da localização no mapeamento de variáveis da rotina. Quando o formulário usa localização, valor maior que 0 copia a localização da requisição de origem e 1 deixa a localização somente leitura (cópia obrigatória); com 0 a rotina mantém a localização sem cópia. A tela de configuração do processo grava 1, ou 2 com a opção "opcional" marcada, e a documentação do processo mostra 2 como "opcional" e 1 como "obrigatória".

| chave | categoria |
|---|---|
| `0` | definido pelo produto |
| `1` | definido pelo produto |
| `2` | definido pelo produto |
